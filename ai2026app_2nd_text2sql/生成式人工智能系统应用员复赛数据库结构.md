# 数据库结构说明


 
日期字段以 TEXT 存储，日期采用 YYYY-MM-DD；payments.paid_at 采用 YYYY-MM-DD HH:MM:SS；store_targets.target_month 采用 YYYY-MM。

> 本说明仅提供数据库结构、字段含义、主键与外键关系，不提供枚举值、业务计算公式或标准 SQL。

## regions — 销售区域

| 字段 | 类型 | 含义 | 约束 |
|---|---|---|---|
| `region_id` | INTEGER | 区域ID | PK |
| `region_name` | TEXT | 区域名称 |  |

## stores — 线下门店

| 字段 | 类型 | 含义 | 约束 |
|---|---|---|---|
| `store_id` | INTEGER | 门店ID | PK |
| `store_name` | TEXT | 门店名称 |  |
| `region_id` | INTEGER | 所属区域ID | FK → regions.region_id |
| `city` | TEXT | 所在城市 |  |
| `district` | TEXT | 所在区县 |  |
| `store_type` | TEXT | 门店类型 |  |
| `open_date` | TEXT | 开业日期 |  |

## warehouses — 仓库信息

| 字段 | 类型 | 含义 | 约束 |
|---|---|---|---|
| `warehouse_id` | INTEGER | 仓库ID | PK |
| `warehouse_name` | TEXT | 仓库名称 |  |
| `region_id` | INTEGER | 所属区域ID | FK → regions.region_id |
| `city` | TEXT | 所在城市 |  |

## categories — 商品类别

| 字段 | 类型 | 含义 | 约束 |
|---|---|---|---|
| `category_id` | INTEGER | 类别ID | PK |
| `category_name` | TEXT | 类别名称 |  |

## brands — 商品品牌

| 字段 | 类型 | 含义 | 约束 |
|---|---|---|---|
| `brand_id` | INTEGER | 品牌ID | PK |

## suppliers — 商品供应商

| 字段 | 类型 | 含义 | 约束 |

## products — 商品主数据

| 字段 | 类型 | 含义 | 约束 |
|---|---|---|---|
| `product_id` | INTEGER | 商品ID | PK |
| `product_name` | TEXT | 商品名称 |  |
| `category_id` | INTEGER | 商品类别ID | FK → categories.category_id |
| `brand_id` | INTEGER | 品牌ID | FK → brands.brand_id |
| `supplier_id` | INTEGER | 供应商ID | FK → suppliers.supplier_id |
| `list_price` | REAL | 当前标价 |  |
| `cost_price` | REAL | 当前成本价 |  |
| `product_status` | TEXT | 商品状态 |  |

## product_price_history — 商品历史价格

| 字段 | 类型 | 含义 | 约束 |
|---|---|---|---|
| `price_history_id` | INTEGER | 历史价格记录ID | PK |
| `product_id` | INTEGER | 商品ID | FK → products.product_id |
| `effective_from` | TEXT | 价格生效开始日期 |  |
| `effective_to` | TEXT | 价格生效结束日期；空值表示当前仍有效 |  |
